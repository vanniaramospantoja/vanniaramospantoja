# 👋 ¡Hola! Soy Vannia Angélica Ramos Pantoja

### 💻 Desarrolladora Frontend | JavaScript | React.js

Soy desarrolladora frontend apasionada por la creación de aplicaciones web modernas, intuitivas y funcionales. Me interesa construir experiencias digitales que combinen un buen diseño, rendimiento y una excelente experiencia de usuario.

Actualmente estoy profundizando en **React.js** para desarrollar aplicaciones frontend escalables y aplicar buenas prácticas de arquitectura basada en componentes. Además, estoy dando mis primeros pasos en el desarrollo backend con **Node.js** y **Express.js**, con el objetivo de comprender el ciclo completo de desarrollo de aplicaciones web.

Además de mi crecimiento técnico, participo en iniciativas de impacto social como **colaboradora de Global Shapers Santander**, una comunidad impulsada por el **Foro Económico Mundial (World Economic Forum)**, donde jóvenes líderes trabajan en proyectos orientados a generar un impacto positivo en la sociedad desde el ámbito local.

En este perfil comparto mis proyectos personales, prácticas de desarrollo y todo aquello que voy aprendiendo mientras continúo creciendo como desarrolladora.
